🧪 Track Analysis
System-prompt / secret disclosure: Tested whether a user could extract intentionally embedded secrets from the system prompt. No leaks were observed, indicating robust safeguards against direct prompt attacks.
RAG context exfiltration: Tested if the retrieval-augmented generation system could be manipulated to leak sensitive information from retrieved or poisoned documents. No leak was detected, suggesting reliable isolation of protected content.
Memorization / PII regurgitation: Assessed whether the model emits memorized personal information or training data. No PII or sensitive regurgitation occurred, though minor recall of public data was noted (not sensitive).
